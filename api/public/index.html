SmartToolBox

Inventory and drawer assignment for your toolbox

Inventory Overview

Keep one place to track which drawer holds each tool. Use the API to search by tool name or assign a tool to a new drawer number.

Find tool: GET /api/tools/find?tool=10mm%20socket

Assign tool: POST /api/tools/assign with JSON {"tool":"10mm socket","drawerNumber":2}

Toolbox Inventory

Track what belongs in each drawer and keep the list persistent on the device.

Transcription Settings

Choose where push-to-talk audio is transcribed. API keys remain on the Pi and are never shown here.

Recent Requests

Structured request history from the API, including result and status code.
