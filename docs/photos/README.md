# Photos

Photographs of the box as it was built, one file per occasion, named
`<what>-<yyyy-mm-dd>.jpg`. Resize to about 2000 px on the long side before
committing - a phone's full-size original is several megabytes and the repo
keeps every version forever.

| Photo | Shows |
|---|---|
| `wiring-2026-09-02.jpg` | The 2026-09-02 rewire, every Grove port populated. The wiring that `docs/HARDWARE.md` describes. |
| `box-2026-10-04.jpg` | The latest build, mounted on the Husky two-drawer box: Pi Zero 2 on the left, the XIAO on its expansion base with the OLED showing a found Phillips screwdriver, the 8x8 matrix smiling, and the Vision AI V2 in its printed cradle on the right. Taken the day "Hi ESP" was first proven. |
